# NetOps Hub

Το NetOps Hub είναι μια Django εφαρμογή διαχείρισης και παρακολούθησης δικτυακών συσκευών και cloud υποδομών.

## Στόχος

Η εφαρμογή θα επιτρέπει:

- Διαχείριση routers, switches, servers και virtual machines
- Καταγραφή IP διευθύνσεων
- Παρακολούθηση της κατάστασης των συσκευών
- Καταγραφή τεχνικών περιστατικών
- Προβολή στατιστικών μέσω dashboard
- Δημιουργία αναφορών

## Τεχνολογίες

- Python
- Django
- PostgreSQL
- Bootstrap
- Microsoft Azure
- GitHub Actions

## Κατάσταση

Το project βρίσκεται υπό ανάπτυξη.
